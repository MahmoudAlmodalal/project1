# BorrowHub — Frontend Demo

BorrowHub is now a **frontend-only interactive demo** for a university lab equipment borrowing experience. It has no backend, database, API routes, authentication service, or external state.

## What is included

- Arabic-first RTL interface with English toggle.
- Student catalog with search, categories, availability filter, polished equipment cards, and booking modal.
- Student portal and admin screens for demonstrating the main product flows.
- Demo booking submissions saved to `localStorage` so the flow works without a server.
- Responsive visual system based on IBM Plex Sans Arabic, Indigo/Violet brand colors, semantic status badges, and accessible controls.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

> This repository intentionally excludes the previous backend implementation. Admin data and actions shown in the screens are presentation-only demo states.
