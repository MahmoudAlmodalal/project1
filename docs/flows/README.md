# فهرس مسارات المهام المحددة (Modular Task Flows Index)

تم تقسيم مسار المستخدم الشامل (User Flow) إلى 6 مسارات مهام مستقلة ومحددة لتسهيل التنفيذ، والتطوير، واختبار كل وحدة برمجية بشكل مستقل:

1. **[مسار مصادقة وإدارة الحسابات](01-auth-account-flow.md)** (`01-auth-account-flow.md`):
   - تسجيل الطالب، انتظار التفعيل، تسجيل الدخول، وتدقيق المشرفين.
2. **[مسار تصفح وإنشاء طلب استعارة](02-request-creation-flow.md)** (`02-request-creation-flow.md`):
   - استعراض الكتالوج، فحص التوفر، التحقق من حد الإعارات (2 max)، ورفع الطلب.
3. **[مسار مراجعة واعتماد الطلبات وإلغائها](03-approval-and-cancellation-flow.md)** (`03-approval-and-cancellation-flow.md`):
   - إلغاء الطالب الذاتي، مراجعة المشرف، إدخال سبب الرفض، والحجز الذري للمخزون (`available - 1, reserved + 1`).
4. **[مسار الاستلام والتسليم المكتبي](04-pickup-and-checkout-flow.md)** (`04-pickup-and-checkout-flow.md`):
   - مهلة 48 ساعة للاستلام، معالجة انتهاء الحجز (`EXPIRED`)، وإتمام التسليم (`CHECKED_OUT`).
5. **[مسار الإرجاع، الفحص، وتسجيل التلفيات](05-return-and-inspection-flow.md)** (`05-return-and-inspection-flow.md`):
   - فحص العتاد، الإرجاع السليم (إعادة المتاح)، والإرجاع المتضرر (تقرير الضرر والتحويل للصيانة).
6. **[مسار رصد التأخير والمتابعة](06-overdue-tracking-flow.md)** (`06-overdue-tracking-flow.md`):
   - جدولة رصد المهلة (10 أيام)، تنبيه الطالب، وإدراج السجل في لوحة متابعة المشرفين.
